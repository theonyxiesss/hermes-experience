# Критерии отбора — теперь в criteria.json, не здесь

Раньше здесь был текстовый промпт для ИИ. Мы переделали пайплайн так, чтобы
отбор вакансий шёл **без ИИ** — обычным кодом по правилам. Заполняйте
[`criteria.json`](./criteria.json) — вот его поля человеческим языком:

| Поле | Что значит |
|---|---|
| `roles_include` | Названия ролей, которые подходят (ищутся как подстрока в заголовке/описании) |
| `roles_exclude` | Роли, которые НЕ подходят — при совпадении вакансия сразу получает score=0 |
| `keywords_include` | Стек/технологии, которые вам нужны — чем больше совпадений, тем выше score |
| `keywords_exclude` | Стек, которого лучше избегать — сразу score=0 при совпадении |
| `salary_min` / `currency` | Минимальная зарплата (если в вакансии не указана — не штрафуется) |
| `locations` / `remote_ok` | Подходящие города + разрешена ли удалёнка |
| `red_flag_keywords` | Фразы-маркеры плохих вакансий ("разъездной характер" и т.п.) — сразу score=0 |
| `blacklist_companies` | Компании, куда точно не хотите — сразу score=0 |
| `score_weights` | Сколько баллов из 100 даёт каждый критерий (сумма = 100) |

Этот файл (`criteria_prompt.md`) можно использовать просто как памятку/заметки
для себя в свободной форме — код его не читает, машинно читается только
`criteria.json`.
